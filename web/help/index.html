Popular topics

Stashbar isn’t spotting links

Check Settings → General → Watch clipboard for links. Stashbar only offers web addresses, and skips links you’ve already stashed.

Change the ⌥S shortcut

Settings → Shortcuts. Click the keys and press a new combo. Add ⇧ to it to stash instantly.

Links not syncing

Make sure you’re signed in on both Macs with the same Apple or Google account. Settings → Account → Sync now forces a sync.

“Can’t verify the developer”

System Settings → Privacy & Security → Open Anyway. Or run xattr -cr /Applications/Stashbar.app once.

Import bookmarks

Export bookmarks as HTML from your browser, then Settings → Data & privacy → Import.

From guest to account

Sign in from Settings → Account. Every link on this Mac moves to your account — nothing gets lost.
